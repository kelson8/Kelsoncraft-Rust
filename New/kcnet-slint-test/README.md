# Slint Test for Rust

This is a basic Slint UI test with Rust.
So far there isn't much in here, but I may add to this in the future.

I put this in this repo to experiment with and see how this UI works.

This is mostly edited with RustRover, 
 and there is a Slint extension you can download to make it easier on there.

**Folders**

### Src
* main.rs - Contains the startup logic for the UI.

### UI

* app-window.slint - This contains the main app and window that draws for it.
